# Semigroups and Monoids
In maths, there are certain properties and laws that enables complex arithmetic to take place that 
guarantees correct results.

### Properties of Binary Operations
Addition is a binary operation that is closed, i.e. (Int, Int) => Int:
1 + 3 = 4

Addition has an identity element:
x + 0 = x

Addition is associative:
(1 + 3) + 4 = 1 + (3 + 4)

The same can be said of multiplication, string concatenation, etc. but not Substraction:
(4 - 1) - 3 != 4 - (1 - 3)

These 2 properties define Semigroup and Monoids.
Just as being aware of these properties gives you correct results, the same can be said of software code.

## Semigroups
Semigroups have a single property:
* combine: (A,A) => A

```scala
trait Semigroup[A] {
  def combine(x:A, y:A): A
}
```

## Monoids
Monoids have the same property as a Semigroup with one additional property:
* empty: A

```scala
trait Monoid[A] extends Semigroup[A] {
  def empty: A
}
```
The `empty` must be the identity element.
Unlawful instances are dangerous as they can yield unpredictable results when used with Cats.
