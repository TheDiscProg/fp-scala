# 4. Category Theory
CT provides much of the mathematical foundation for FP.
Basically, all the research in CT feeds back into FP, thus enabling multi-thread safe software.

It consists of:
* Objects   == Types
* Morphisms == Functions
* Composition == Function compositions
* Identity Morphism == Identity Functions

## Functors
A functor is one of the most important concepts that connect CT with FP.
Informally, a functor allows us to transform values inside of a context without
changing the structure of the context.

```scala
val result: Option[Int] = Some(10).map(_ * 2)
```
In this case, the `Option` functor allows us to apply a function to the value inside.

In cats, this would  be:
```scala
def double[F[_]: Functor](fa: F[Int]): F[Int] = Functor[F].map(fa)(_ * 2)
```
