# What is FP?

## History
- First formulated as a formal system in 1930s by Alonzo Church as Lambda Calculus
- 1937 Alan Turing demonstrated that Lambda Calculus and Turing machines are the same
- 1950s - LISP developed (from which came Clojure)
- 1987 Haskell started to be developed

## Why Now?
Simply because hardware has improved to the point that the bottleneck is now programmers using imperative style of programming.
This affects:
- How the compiler optimizes the code (replacing function calls with inline methods)
- Security vulnerabilities due to memory dump or stack trace
- Most code will run on a single thread rather than on multiple threads

## Fundamentals
- Pure Functions - these must be deterministic, returning the same output and cause no hidden change
- Immutability - Data cannot be modified after it is created
- First-Class and Higher Order Functions - functions are treated as values - they can be saved in variables, passed to other functions, or returned from them
- Referential Transparency - An expression can be safely replaced by it's resulting value without changing program behaviour
- Function Composition - Small, simple functions are chained together like a pipeline
- Declarative Programming - Code describes what to solve rather than solving it (imperative)
- Recursion: Loops that rely on changing counter variables are replaced with recursive function calls
