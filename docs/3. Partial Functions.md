# 3 Partial Functions/Total Functions
When discussing partial functions, there are two distinct concepts.
Basically, a function is partial if it is not defined for all input values.
A function that is defined for all input values is a total function.

## 1. Partial function in a mathematical sense (f: A' -> B)
The following method isn't defined for all values:
```
 def divideBu(x: Int, y: Int): Int
```

## 2. Scala's PartialFunction (f: A' -> B)
Scala has an explicit trait `PartialFunction[-A, +B]`
It's main purpose is to indicate explicitly that the function doesn't handle all inputs.

## 3. Total Functions (f: A -> B)
As mentioned above, a  total function is defined for all values.

## 4. Lifting Partial functions to total functions (f: A -> F[B])
An example: `def divideBy(x: Int, y: Int): Option[Int]`
i.e. `f: A -> Option[B]`
