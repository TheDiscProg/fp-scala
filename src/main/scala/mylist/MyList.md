# MyList
## Initial non-FP List Library
Create a library that will:
1. Store a list of items
2. You can add an item to the beginning of the list
3. You can add an item at the end of the list
4. You can get sort the items
5. Remove items that match a given criterion


## Implementing MyList

| Method | Description |
|--------|-------------|
| `addHead(a)` | Add an item to the beginning of the list |
| `addTail(a)` | Add an item at the end of the list |
| `sort` | Sort items using an implicit/contextual ordering |
| `delete(p)` | Remove items that match a given criterion |
| `size` | Get the number of items in the list |
| `isEmpty` | Check if the list is empty |
| `toScalaList` | Convert to a Scala List |
